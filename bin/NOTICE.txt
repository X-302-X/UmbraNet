UmbraNet — сведения о сторонних компонентах в папке bin/
═══════════════════════════════════════════════════════════════════════════════

UmbraNet распространяется под лицензией GPLv3 (см. LICENSE в корне репозитория).
В папке bin/ вместе с программой поставляются сторонние компоненты. Их авторские
права принадлежат соответствующим правообладателям; ниже — сведения о каждом
компоненте, его происхождении и лицензии.

───────────────────────────────────────────────────────────────────────────────
1. WinDivert.dll, WinDivert64.sys — драйвер перехвата трафика
───────────────────────────────────────────────────────────────────────────────
Проект:      WinDivert (Windows Packet Divert)
Автор:       basil (https://reqrypt.org/windivert.html, https://github.com/basil00/Divert)
Лицензия:   двойная: GNU LGPL version 3 ИЛИ GNU GPL version 2 (на выбор).
             Тексты лицензий: https://www.gnu.org/licenses/ и
             https://reqrypt.org/windivert-doc.html (раздел License)
Назначение:  перехват и модификация сетевых пакетов. Используется движком
             обработки трафика e1-spike.exe (собственное ядро UmbraNet,
             исходники — в составе проекта).
             Обнаружение: некоторые антивирусы помечают WinDivert как RiskTool —
             это ложное срабатывание на саму технологию перехвата пакетов.

───────────────────────────────────────────────────────────────────────────────
2. *.bin — шаблоны полезной нагрузки (данные)
───────────────────────────────────────────────────────────────────────────────
Файлы:       tls_clienthello_*.bin  — снимки TLS ClientHello (SNI-шаблоны),
             quic_initial_*.bin     — снимки QUIC Initial-пакетов,
             stun.bin               — шаблон STUN-трафика.
Назначение:  шаблоны, которые движок e1-spike.exe использует для разбиения/
             подмены фрагментов трафика при обработке (файлы данных, не код).
Происхождение: поставляются вместе с UmbraNet как вспомогательные данные
             стратегий; сформированы из открытых сетевых протоколов (RFC 8446
             TLS 1.3, RFC 9000 QUIC, RFC 5389 STUN).

───────────────────────────────────────────────────────────────────────────────
Примечания
───────────────────────────────────────────────────────────────────────────────
• Исходный код перечисленных компонентов доступен по ссылкам выше.
• UmbraNet не изменяет двоичные файлы компонентов и распространяет их «как есть».
• Движок e1-spike.exe — собственный компонент UmbraNet (исходный код в составе
  проекта, лицензия GPLv3); в этот список сторонних компонентов не входит.
• Этот файл носят информационный характер; условия лицензий определяются
  лицензионными текстами правообладателей по приведённым ссылкам.
